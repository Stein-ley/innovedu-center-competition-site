============================================================ 1. PROJECT
OVERVIEW ============================================================

Project name: Innovedu Center Competition Studio

Purpose: A web-based competition and examination management platform.
Organizers should be able to create and manage multiple independent
exams. Participants enter using individual access codes and complete
timed assessments.

Target deployment: - Cloudflare Workers: application and API -
Cloudflare D1: database - Cloudflare static assets: frontend files -
Wrangler: command-line deployment from Windows - GitHub is intentionally
not part of the preferred deployment workflow.

Expected usage: - Desktop-first interface - Approximately 50–200
participants - Competition deadline approaching

IMPORTANT STATUS DISTINCTION: The capabilities below describe the
requested/target system. They are not proof that every feature is
implemented or working. The current deployment cannot be reached in the
user’s browser, so end-to-end functionality has not been verified.

============================================================ 2. COMPLETE
TARGET SITE CONFIGURATION AND CAPABILITIES
============================================================

A. ORGANIZER / ADMIN ACCESS - Organizer login page. - Organizer
credentials stored as Cloudflare Worker secrets: ADMIN_USERNAME
ADMIN_PASSWORD SESSION_SECRET - Authenticated organizer dashboard. -
Organizer controls separated from the participant interface.

B. DASHBOARD AND EXAM MANAGEMENT - Dashboard listing all
exams/competitions. - Create, edit, and delete exams. - Start/stop or
independently host each exam. - Each exam has its own configuration and
participant access. - Managing one exam should not unintentionally
affect another. - Blank/default template available when creating an
exam. - Organizer name/title, event/competition title, and exam title
are separate fields.

C. QUESTIONS AND EXAM CONTENT - Multiple-choice questions. -
Written-answer questions. - Images attached to questions. - Edit exam
and question content. - JSON import and export. - Blank template as the
default starting point. - Automatic grading for multiple-choice
questions. - Manual grading for written answers.

D. PARTICIPANT ACCESS AND REGISTRATION - Separate participant-facing
exam page. - Individual access code for each participant. - Collect
participant information before the exam. - Display exam/competition
rules before starting. - Access code grants access to the relevant
exam. - Each access code can be used for one attempt only. - Prevent
reuse of a code to take the same exam again.

E. EXAM EXPERIENCE - Timed exam. - Participants answer questions and
submit/finish. - Finish/confirmation page after submission. -
Participant must not see their score immediately after finishing. -
Participant interface is separate from the organizer dashboard.

F. RESULTS AND GRADING - Automatic MCQ grading. - Manual written-answer
grading by organizer. - Organizer can review submissions. - Organizer
can view results. - Results can be exported. - Participant score is not
displayed on the finish page.

G. DATA AND INFRASTRUCTURE - Cloudflare D1 stores exam and
participant-related data. - SQL migration initializes database tables. -
Cloudflare Worker handles API/application requests. - Static frontend
files are served from the public directory. - Frontend and API are
intended to use the same Worker deployment.
